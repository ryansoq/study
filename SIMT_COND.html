SIMT 分支機制

一個 warp 只有一條指令流，可是 if 讓一半的 lane 想走 then、另一半想走 else。GPU 不能真的讓 lane 各跳各的，於是編譯器在分支前後插入額外的指令，讓兩條路都跑一遍，每次只讓對的那一半寫回結果。這頁用同一段程式，逐步比較 NVIDIA、AMD、PowerVR、Mali 插進去的 code 長什麼樣，以及硬體在每一步記了什麼。

每一家都要解決的三件事

1 · 哪些 lane 要寫回

每條 lane 要有一個 bit 決定這條指令要不要寫回結果。AMD 是 EXEC，NVIDIA 是 predicate 加上硬體 active mask，PowerVR 是每個 instance 的 Pe。

2 · 另一組何時跑、在哪會合

then 跑完要切到 else，最後全部合回來。差別在這份狀態記在哪裡：硬體 stack、barrier 暫存器、SGPR，或每個 instance 自己的計數器。

3 · 一整組都沒人就跳過

mask 全是 0 時還逐條執行就是浪費，所以都有「沒人 active 就整段跳過」的機制，例如 AMD 的 s_cbranch_execz。

在這三件事之前，編譯器還有一步 divergence analysis。如果能證明條件對整個 warp 都一樣（例如來自 uniform 或 kernel 參數），就只產生一般的跳躍，完全不需要 mask。另外，很短的分支通常直接改成 predicate 或 select，讓兩邊都算，不產生分支。

      迴圈：有些 lane 先離開

      迴圈的難處在於每條 lane 的迭代次數不同。先離開的 lane 必須關掉，直到最後一條 lane 也離開，再全部恢復。

      PowerVR 那段是依 ISA 文件中 CNDLT 的 pseudo-code 組出來的示意，tst 和 br 的寫法不是真實語法。

      延伸：每條 lane 要呼叫不同的函式

      function pointer 或非 uniform 的 descriptor 會讓每條 lane 的跳躍目標都不一樣，mask 的做法沒辦法直接處理。各家的解法都是一個 waterfall 迴圈：每一輪挑一條 lane 的目標，讓目標相同的 lane 一起執行，執行完就關掉，直到所有 lane 都處理過。
